PayViewer

Ứng dụng theo dõi biến động số dư ngân hàng qua SePay cho Windows

Giới thiệu Hướng dẫn Bảo mật Hỗ trợ

Giới thiệu

PayViewer là một ứng dụng dành riêng cho hệ điều hành Windows, giúp bạn theo dõi lịch sử giao dịch ngân hàng một cách nhanh chóng và tiện lợi thông qua API của SePay. Ứng dụng hoạt động độc lập, không cần phần cứng bổ sung (như ESP32), phù hợp cho các cửa hàng, cá nhân muốn quản lý dòng tiền ngay trên máy tính.

Hướng dẫn sử dụng

Bước 1: Lấy API Token
Truy cập vào trang quản trị SePay, vào mục Cài đặt API để tạo một mã Token mới.
Bước 2: Cấu hình PayViewer
Mở ứng dụng, nhập Số tài khoản và API Token đã lấy ở Bước 1 vào mục cài đặt. Nhấn Lưu.
Bước 3: Theo dõi giao dịch
Nhấn Làm mới để bắt đầu nhận dữ liệu. Bạn có thể bật tính năng Đọc giao dịch (Ting Ting) để nhận thông báo âm thanh khi có tiền về.

Chính sách Bảo mật (Privacy Policy)

Chúng tôi cam kết bảo vệ quyền riêng tư của bạn. PayViewer hoạt động theo các nguyên tắc sau:

  • Dữ liệu API: Mã API Token và số tài khoản của bạn được lưu trữ cục bộ trên máy tính cá nhân của bạn (trong file pay_viewer.json). Chúng tôi không gửi dữ liệu này về bất kỳ máy chủ nào khác ngoài SePay.
  • Dữ liệu giao dịch: Thông tin giao dịch được tải trực tiếp từ SePay về ứng dụng của bạn và chỉ hiển thị trên màn hình. Chúng tôi không thu thập, lưu trữ hay chia sẻ lịch sử giao dịch của bạn.
  • Quyền hạn: Ứng dụng chỉ yêu cầu quyền truy cập Internet để kết nối với API SePay và quyền ghi file cục bộ để lưu cấu hình ứng dụng.
